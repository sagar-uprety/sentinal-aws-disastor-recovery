# sentinel-aws-dr

AWS Disaster Recovery sentinel system.

## Stack

- **Infrastructure**: Terraform (AWS provider ~6.0)
- **Language**: Go
- **Monitoring**: Prometheus + Grafana

## Conventions

- Feature branches + conventional commits
- Ask before committing
- PR after each milestone
- Single-line comments only where non-obvious
- Follow terraform style guide

## Commands

- `/terraform-style-guide` - HCL conventions
- `/promql` - Metric queries
- `/dashboarding` - Grafana panels
- `/drawio` - Architecture diagrams

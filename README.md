# Sentinel - Resilient Status Page on AWS

A multi-AZ AWS workload with pilot light DR in a second region, fully defined in Terraform. The app monitors uptime of external sites and of itself, so the recorded failover demo shows the system observing its own outage and recovery, with measured RTO and RPO.

Portfolio project by Sagar Koirala. Target: Senior DevOps Engineer / Platform Engineer (Germany).

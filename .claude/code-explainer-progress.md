# Code Explainer Progress - Pilotlight (aws-pilotlight-multi-region-dr)

## Overview
Multi-region AWS disaster recovery project, pilot-light strategy. Two independent systems: a PostgreSQL-backed URL-shortener workload (active in one region, pilot-light standby in a second, compute scaled to 0 in secondary until failover) and a monitoring service that lives in its own region/account-level failure domain so it survives a full workload-region failover. Terraform for infra, Go for the workload and sentry services.
